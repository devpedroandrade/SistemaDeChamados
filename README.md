API REST para controle de chamados de suporte, conforme desafio proposto.

Para executar:

1. Tenha o [.NET 10 SDK](https://dotnet.microsoft.com/download) instalado.
2. Extraia os arquivos.
3. No terminal, dentro da pasta do projeto, execute: dotnet run
4. Acesse o Swagger em: http://localhost:5256/swagger

O banco de dados SQLite (w5i_desafio.db) será criado automaticamente com dados iniciais.
